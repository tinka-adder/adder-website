# adder.care — website

De website van adder. Eén pagina: `index.html`, met de letters in `fonts/`.

## Zo pas je iets aan

1. Open GitHub Desktop, kies **adder-website** en klik **Fetch origin** (en **Pull** als dat verschijnt). Zo werk je altijd op de nieuwste versie.
2. Pas `index.html` aan (of vraag het aan Claude).
3. Schrijf in GitHub Desktop kort wat je veranderde, klik **Commit to main** en dan **Push origin**.
4. Netlify zet het binnen een minuutje online op adder.care.

Werk niet met twee tegelijk aan dezelfde pagina zonder het even af te spreken.

## Letters

Alte Haas Grotesk is freeware en mag verspreid worden zolang het licentiebestandje erbij zit. Laat dat dus in `fonts/` staan.
Voeg geen andere lettertypes toe zonder eerst de licentie te checken: deze repository is publiek.
